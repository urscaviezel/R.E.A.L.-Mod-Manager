## 1.0.0 – 2026-10-22

First public release · Erste öffentliche Version

**English**
- Install, update and cleanly uninstall R.E.A.L. VR with a full before/after journal and leftover check
- Supports current and older mod versions (e.g. v19); legacy removal for installs made without the manager
- Game discovery via store lists (Steam, Epic, GOG, Ubisoft, EA, Rockstar, Amazon, Heroic, Xbox) with cache
- Library with all moddable games, compatibility assessment, store info and covers
- Registry snapshots (mod keys only), Windows restore point, per-game NVIDIA profile reset
- Dark/light theme, German/English/French, downloadable languages
- Automatic update check via GitHub releases, data clean-up
- Portable version (folder with EXE) and installer

**Deutsch**
- Installieren, Aktualisieren und sauberes Deinstallieren von R.E.A.L. VR mit vollständigem Vorher/Nachher-Protokoll und Rückstandsprüfung
- Unterstützt aktuelle und ältere Mod-Versionen (z.B. v19); Entfernung ohne Protokoll für ältere Installationen
- Spielesuche über die Store-Listen mit Cache
- Bibliothek mit allen modbaren Spielen, Kompatibilitäts-Einschätzung, Shop-Infos und Covern
- Registry-Snapshots (nur Mod-Schlüssel), Windows-Wiederherstellungspunkt, NVIDIA-Profil pro Spiel
- Dunkles/helles Design, Deutsch/Englisch/Französisch, Sprachen zum Herunterladen
- Automatische Update-Prüfung über GitHub-Releases, Daten aufräumen
- Portable Version (Ordner mit EXE) und Installer
